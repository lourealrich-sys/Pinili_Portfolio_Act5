# Developer Portfolio Web Application

A clean, modern, and professional portfolio web page built using **HTML5**, **CSS3**, and **Bootstrap 5**. 
---

##  Features

- **Modern & Professional UI/UX**: Gradient-free visual aesthetic utilizing slate gray, deep navy, and crisp primary accents.
- **Responsive Grid Layout**: Fully fluid and optimized across desktop, tablet, and mobile breakpoints via Bootstrap 5.3.
- **Equal-Height Project Cards**: Custom Flexbox and strict image aspect-ratio handling (`object-fit: cover`) to ensure uniform project card sizing regardless of image dimensions or text lengths.
- **Bootstrap Icons & Google Fonts**: Clean typography using the **Inter** typeface paired with minimalist vector iconography.
- **Interactive UI Elements**: Subtle micro-interactions, custom card hover elevation effects, and focused state stylings.
- **Contact Form Layout**: Styled HTML form interface ready for backend/API integration.

---

##  Built With

* [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) - Semantic markup & layout engine
* [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) - Custom CSS variable properties, Flexbox alignment, and media rules
* [Bootstrap 5.3.2](https://getbootstrap.com/) - Responsive grid system, utilities, and components
* [Bootstrap Icons 1.11.1](https://icons.getbootstrap.com/) - Crisp vector icons
* [Google Fonts (Inter)](https://fonts.google.com/specimen/Inter) - Clean, legible digital typography
